# **App Name**: EchoJournal

## Core Features:

- User Authentication: Secure user authentication using Google OAuth and email/password via Supabase.
- Voice/Text Journaling: Create journal entries using voice with Google Cloud Speech-to-Text transcription (5-minute max) or direct text input.
- Echo Mode: Use Gemini 2.5 Flash to analyze past journal entries and identify thematic connections; incorporates a tool that will determine when and if there are thematic connections.
- Mood Insights: AI-powered sentiment analysis of journal entries, visualized with charts using Recharts.
- Dynamic Themes: Choose from 6 dynamic themes: Dark Cosmos, Pink Dreams, Cream, Neon, Forest, Ocean.
- Starry Background: A live starry background with 150+ animated stars and click-burst effects.
- Duolingo Grade Streak Page: Page where you can add in your daily Duolingo grade and review your streak.

## Style Guidelines:

- Primary color: Soft lavender (#E6E6FA), reflecting calmness and introspection, fitting for a journaling app.
- Background color: Light grey (#F0F0F0), providing a clean and neutral backdrop.
- Accent color: Muted violet (#C4A484) to highlight key elements and actions.
- Font: 'Plus Jakarta Sans' (sans-serif) for a modern and accessible feel. Note: currently only Google Fonts are supported.
- Holographic icons for the bottom navigation tabs, enhancing the premium feel.
- Professional glassmorphism design, providing a frosted glass effect for UI elements.
- Smooth page transitions powered by Framer Motion for a fluid user experience.
